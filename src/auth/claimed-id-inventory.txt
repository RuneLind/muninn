# The claimed-id and CORS inventory - PR C's acceptance item 12.
#
# Re-derived from the source by src/auth/inventory.ts on every test run and
# compared against this file. It exists because §2 of the NAV-login plan makes
# the inventory a COMMAND rather than a number: two successive drafts of that
# document cited a route count that had already gone stale, and the narrow form
# of the first grep missed the two app.on("HEAD", ...) routes entirely.
#
# Format:  <file> | <signature> | <disposition>   # optional note
# Dispositions are the vocabulary in src/auth/inventory.ts. A row with none, or
# with one not on that list, FAILS - which is the point: a route added later
# lands here as unassigned work rather than as a silently unguarded surface.
#
# Line numbers are deliberately absent. A body/query row carries a COUNT
# instead, because those reads have no route path to key on - so a new one in a
# file already listed moves the number and fails the test.
